## วิธีอัปเดตไฟล์นี้

ระหว่างทำ: ติ๊ก subtask `- [x]` ใน `tasks/Pn.md`

ปิด task (subtask ครบ) แล้วทำ 4 อย่าง:

1. ติ๊กหัวข้อ `### Pn-XX` ใน `tasks/Pn.md`
2. แก้ตัวเลข "คืบหน้า (task)" + สถานะเฟสในตารางภาพรวมด้านบน
3. เพิ่มบรรทัดใน "บันทึกความคืบหน้า" — ทำอะไรไป + ถ้าเปลี่ยนจากแผนให้เขียนไว้
4. commit อ้างรหัส task: `Pn-XX: <สิ่งที่ทำ>`

เจอเรื่องต้องตัดสินใจ → เพิ่มแถวในตาราง "เรื่องที่ติดอยู่" ทันที · ตัดสินใจแล้ว → ย้ายลง "บันทึกการตัดสินใจ" พร้อมเหตุผล
ถ้าพบว่า `PLAN.md` ผิด → แก้ `PLAN.md` ด้วย อย่าให้เอกสารกับโค้ดเล่าคนละเรื่อง
