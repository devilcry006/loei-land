## วิธีอัปเดตไฟล์นี้

เมื่อปิด task ให้ทำ 3 อย่าง:

1. ติ๊ก `- [x]` ในไฟล์ `tasks/Pn-*.md` ของ task นั้น
2. แก้ตัวเลข "คืบหน้า" และสถานะเฟสในตารางภาพรวมด้านบน
3. เพิ่มบรรทัดใน "บันทึกความคืบหน้า" ว่าทำอะไรไป และถ้ามีอะไรเปลี่ยนจากแผนเดิมให้เขียนไว้ด้วย

ถ้าเจอเรื่องที่ต้องตัดสินใจระหว่างทาง → เพิ่มแถวในตาราง "เรื่องที่ติดอยู่" ทันที อย่าเก็บไว้ในหัว
เมื่อตัดสินใจแล้ว → ย้ายลง "บันทึกการตัดสินใจ" พร้อมเหตุผล
