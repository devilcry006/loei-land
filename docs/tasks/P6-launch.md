## เป้าหมาย

ผ่านทุกข้อในเช็กลิสต์ก่อนเปิดให้คนทั่วไปใช้ — ทั้งด้านกฎหมาย (PDPA) ความปลอดภัย ประสิทธิภาพ และเนื้อหา

> เฟสนี้ **ห้ามข้าม** เว็บที่เก็บชื่อ เบอร์โทร และข้อมูลทรัพย์สินของคนอื่น ถ้าข้อมูลรั่วคือเรื่องใหญ่กว่าเว็บล่ม

## Checklist

      ต้องระบุ: ผู้ควบคุมข้อมูลคือใคร, เก็บอะไรบ้าง, ฐานทางกฎหมาย, เก็บนานแค่ไหน, แชร์ให้ใคร, ช่องทางใช้สิทธิ์, ช่องทางร้องเรียน
- [ ] **P6-02** ช่องทางใช้สิทธิ์เจ้าของข้อมูล (PDPA ม.30-33) — ฟอร์มขอดู/ขอแก้/ขอลบ + ปุ่มลบจริง (hard delete) ใน `/admin` พร้อมบันทึก `audit_log`

## เกณฑ์ว่า "เสร็จ"

- เปิดเว็บด้วยเบราว์เซอร์โหมดไม่ระบุตัวตนบนมือถือ แล้วทำครบทุก flow ได้: หาทรัพย์ → ดูรายละเอียด → ดูแผนที่ → ส่งฟอร์มสนใจ
- แอดมินได้แจ้งเตือน เข้าหลังบ้าน อนุมัติ และเห็นผลขึ้นเว็บ
- ไม่มีคำว่า `owner_`, `deed_number`, `exact_lat` ปรากฏใน HTML/JS ที่ส่งถึงเบราว์เซอร์
- Search Console ไม่ขึ้น error
- ตอบได้ว่า "ถ้าลูกค้าโทรมาขอให้ลบข้อมูล จะทำยังไงภายในกี่นาที"

## ข้อควรระวัง

- **อย่าโปรโมตก่อนมีทรัพย์พอ** — เว็บที่มี 5 แปลงทำให้คนที่เข้ามาครั้งแรกไม่กลับมาอีก และ first impression ซื้อคืนไม่ได้
- ทดสอบ flow ทั้งหมดด้วย**บัญชีที่ไม่ใช่แอดมิน** อย่างน้อยหนึ่งรอบ — บั๊กสิทธิ์การเข้าถึงมักโผล่ตอนทดสอบด้วยบัญชีที่มีสิทธิ์เต็ม
- เตรียมแผนสำรองว่าถ้า Longdo quota เต็มกลางเดือนจะทำยังไง
